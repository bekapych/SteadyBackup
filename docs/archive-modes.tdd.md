Дата: 2026-11-20. Исходный план не использовался; требования получены непосредственно от пользователя.

## Пользовательские сценарии

* Пользователь выбирает один общий архив на запуск задания.
* Пользователь выбирает отдельный архив на каждый файл.
* Пользователь выбирает отдельный архив на каждую строку списка источников.
* Пользователь выбирает отдельный архив на каждую подпапку первого уровня; файлы корня строки
  при этом сохраняются вместе.
* Все варианты сохраняют возможность восстановления и общую ротацию частей одного запуска.
