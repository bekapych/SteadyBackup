# Политика конфиденциальности SteadyBackup

Дата: 15 ноября 2026 г.

SteadyBackup — бесплатная программа резервного копирования для Windows с открытым исходным кодом
([github.com/bekapych/SteadyBackup](https://github.com/bekapych/SteadyBackup)). Программа работает
на компьютере пользователя. У разработчика нет серверов, которые получают, хранят или обрабатывают
данные пользователей.

## Google Drive

Если пользователь сам выбирает Google Drive как место хранения копий, программа запрашивает доступ
`https://www.googleapis.com/auth/drive.file`. С ним программа видит и изменяет **только файлы и папки,
которые создала сама**: загружает архивы резервных копий, перечисляет их и удаляет устаревшие по
правилам хранения, заданным пользователем. Остальные файлы на Диске программе недоступны.

* Токен доступа Google хранится только на компьютере пользователя, зашифрованным средствами Windows
  (DPAPI), и никуда не передаётся, кроме серверов Google.
* Данные Google не передаются разработчику и третьим лицам, не используются для рекламы, аналитики
  или обучения моделей ИИ.
* Использование данных, полученных через API Google, соответствует
  [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
  включая требования Limited Use.

Отозвать доступ можно в любой момент: удалить хранилище в программе или на странице
[myaccount.google.com/permissions](https://myaccount.google.com/permissions).

## Другие данные

Программа не собирает телеметрию. Пароли и токены других хранилищ, подключений и уведомлений хранятся
только на компьютере пользователя в зашифрованном виде.
