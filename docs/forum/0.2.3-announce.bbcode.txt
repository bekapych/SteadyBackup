[b]Что нового[/b]
[list]
[*]Для PostgreSQL добавлен выбор формата выгрузки: Dump custom (.dump, pg_dump -Fc, восстановление через pg_restore) или SQL plain (.sql, pg_dump -Fp, восстановление через psql).
[*]Dump custom остаётся форматом по умолчанию, в том числе для заданий прежних версий. Текстовый SQL plain сжимается 7-Zip с настройками задания.
[*]Проверка verify через pg_restore --list выполняется только для Dump custom; для SQL plain она не применяется.
[*]В окне журнала появилась кнопка «Очистить журнал…». После подтверждения администратор может очистить видимую историю запусков и итоги последних запусков в списке заданий.
[*]Очистка журнала не удаляет и не изменяет резервные копии, задания и текстовые файлы logs\steady.log*.
[/list]

[b]Ограничения[/b]
[list]
[*]Для SQL plain проверка через pg_restore невозможна: эта утилита не читает SQL-скрипты. Восстановление выполняется через psql.
[*]Очистка журнала доступна только администратору и удаляет все записи видимой истории запусков; текстовые журналы службы при этом сохраняются.
[/list]

Реальный PostgreSQL и установка MSI не проверялись.
