# Тексты для темы SteadyBackup на Ru.Board

Тема: <https://forum.ru-board.com/topic.cgi?forum=5&topic=51859>

Здесь лежат готовые к вставке тексты сообщений форума. **Формат — BBCode, а не HTML**:
Ikonboard на Ru.Board понимает `[b]`, `[s]`, `[url=…]`, `[img]`, `[list]` с `[*]`; теги `<b>`,
`<br>`, `<li>` в теле сообщения показываются как обычный текст. Пустая строка — пустая строка
в тексте, никаких `&nbsp;` (форум сохраняет их как `&amp;nbsp;`, и на странице видно «&nbsp;»).
Символ «→» (U+2192) в кодировке форума не сохраняется: вместо него появляется текст `&#8594;`,
поэтому стрелку в текстах не используем — пишем «меню «Настройки», пункт «…»».

ошибочной попытке в HTML-разметке; в дело они не шли.

## Как публикуется выпуск

1. Собрать MSI, взять его SHA-256 из `dist\` и записать заглавными буквами, как в прежних анонсах.
2. Скопировать `announce.bbcode.txt` предыдущей версии в файл новой версии и поправить версию,
   дату, ссылки, SHA-256 и список «Что нового» по `docs/releases/<версия>.md`.
3. В шапке обновить «Последняя версия», «SHA-256», добавить блок «Что нового в <версия>» перед
   блоком предыдущей версии и пункт в «Возможности», если появилась новая функция.
4. Опубликовать.

## Публикация через агента (browse MCP)

Агент может править сообщения сам, если в браузере открыт вход под автором темы (`toyz777`).
Рабочий порядок (проверено 21.11.2026 на 0.1.13):

1. Открыть `postings.cgi?action=edit&forum=5&topic=51859&postno=<N>` — это форма правки.
2. Записать текст в `textarea[name="post"]` (передавать байты из файла и декодировать UTF-8 на странице).
3. Выбрать `preview=no` и отправить форму **нативным** `form.submit()` с `form.target = "_blank"`.
   Ответ открывается в новой вкладке; `fetch` из `page.evaluate` и клик по кнопке не годятся:
   соединение с вкладкой рвётся на время запроса, и правка не доходит.
4. Проверить результат: `span.post` в теме (текст, число `<b>`, `<ul>`, `<li>`, отсутствие `[b]`
   и `&#…;` в тексте).
